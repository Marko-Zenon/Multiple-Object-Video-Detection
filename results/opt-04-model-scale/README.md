## Deviations and notes

1. The venv's `python.exe` was blocked by Windows Application Control on 2026-11-10. Every command ran with the base uv
   CPython 3.12.14 and `PYTHONPATH=<repo>/.venv/Lib/site-packages`. The torch 2.14.1+cu130 and Ultralytics 8.4.207 packages are the same.
2. G0's "7.0 GB" was read as 7.0 × 10⁹ bytes (the stricter reading). Both candidates are far below either reading.
3. The G0 epoch projection uses the per-batch time between the first and last smoke batch. It is a feasibility check only.
   The measured epochs took 32.0 and 29.9 min.
4. About 2.6 GB of GPU memory was used by desktop applications during all runs, with no other compute process.
5. One seed per candidate. val_fast ⊂ val_full. Both were stated in the rule.
